# Fire Sentinel

Fire Sentinel is a GIS-focused project intended to support the visualization and analysis of fire-related information.

> **Project status:** Early development. The web app is currently a Next.js starter scaffold. Fire maps, data ingestion, and alerting are not implemented yet.

## Technology

- **Web:** Next.js, React, TypeScript, and Tailwind CSS
- **Mapping and geospatial tools:** Leaflet, React Leaflet, and Turf.js
- **Data-processing dependencies:** Python packages are listed in `scripts/requirements.txt`

## Run the web app

Node.js and npm installed.

```bash
cd web
npm install
npm run dev
